# Laundry System 🧺

Aplikasi manajemen laundry sederhana untuk UMKM kecil.
Dibuat untuk membantu pemilik laundry beralih dari catatan
manual ke sistem digital yang mudah dipakai.

## Masalah
Pemilik laundry di Makassar masih mencatat order secara manual,
tidak punya sistem antrian yang jelas, dan kesulitan membuat
laporan keuangan harian.

## Solusi
Aplikasi ringan berbasis web/mobile dengan 3 fitur inti:
- Catat order masuk
- Pantau status cucian (antrian FIFO)
- Laporan harian otomatis

## Target Pengguna
Pemilik laundry kecil, non-technical, pakai HP sehari-hari.
