# Laundry System — Agent Context

## Tentang Proyek
Aplikasi manajemen laundry untuk UMKM kecil di Makassar.
Dibuat sebagai tugas kuliah sekaligus portfolio.

## Masalah yang Diselesaikan
- Catatan order masih manual (kertas/buku)
- Tidak ada sistem antrian yang jelas (FIFO)
- Laporan keuangan harian tidak ada

## 3 Fitur Inti (tidak lebih)
1. **Order Masuk** — catat nama, kg, jenis, estimasi selesai
2. **Status Tracker** — lihat semua order aktif dengan urutan FIFO
3. **Laporan Harian** — pemasukan, order selesai, pending, belum bayar

## Prinsip Desain
- Simple tapi polished — setiap fitur harus benar-benar terpakai
- Mobile-friendly — pemilik laundry pakai HP, bukan laptop
- Bahasa Indonesia — target pengguna bukan developer
